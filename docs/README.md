## Значения, подлежащие заполнению

Документы содержат обозначения `<уточняется>` и `<домен>` в местах, где
требуются фактические сведения:

- имя домена и краткое имя домена;
- адреса смежных средств защиты информации и системы мониторинга событий;
- имена контроллера домена, узла виртуализации и АРМ администратора;
- контакты администратора для руководства пользователя;
- применяемые выпуски Kaspersky Security Center, Kaspersky Endpoint
  Security и Debian.

Документы подлежат согласованию после заполнения этих значений и приведения
к принятой в организации форме. Образцы для приведения к форме размещаются
в каталоге `tmp/`.

## Схемы

Файлы `.drawio` открываются в приложении diagrams.net (в том числе в
автономной версии — в аттестованном контуре доступ к веб-версии
отсутствует) либо расширением Draw.io Integration для Visual Studio Code.

Экспорт для включения в документы: **Файл → Экспортировать как → PNG**
с разрешением 300 точек на дюйм либо PDF.

При изменении схем одновременно актуализируйте
`05_diagrams/information_flows.md`: идентификаторы потоков на логической
схеме соответствуют строкам таблиц.
