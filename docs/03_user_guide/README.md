# Руководство пользователя

**Версия документа:** 1.0
**Адресовано:** пользователям автоматизированных рабочих мест, на которых
установлено средство антивирусной защиты

---

## 1. Что установлено на вашем рабочем месте

На рабочем месте установлены две программы, работающие постоянно:

| Программа | Назначение |
|---|---|
| Kaspersky Endpoint Security | Проверяет файлы и защищает рабочее место от вредоносных программ |
| Агент администрирования | Связывает рабочее место с сервером управления: получает настройки и передаёт сведения о состоянии защиты |

Обе программы запускаются автоматически при включении компьютера и не
требуют от вас действий по запуску.

Настройками защиты управляет администратор централизованно. Часть
параметров недоступна для изменения — это не неисправность, а установленный
порядок: единые настройки на всех рабочих местах исключают появление
незащищённых компьютеров.

---

## 2. Как понять, что защита работает

### 2.1. Значок в области уведомлений

| Вид значка | Состояние | Что делать |
|---|---|---|
| Обычный значок программы | Защита работает, базы актуальны | Ничего |
| Значок с восклицательным знаком | Требуется внимание: базы устарели или проверка давно не выполнялась | Оставьте компьютер включённым и подключённым к сети; если через сутки значок не изменился — обратитесь к администратору |
| Значок с красным знаком | Защита отключена или произошёл сбой | Немедленно обратитесь к администратору |
| Значка нет | Программа не запущена | Перезагрузите компьютер; если значок не появился — обратитесь к администратору |

### 2.2. Проверка вручную

Откройте программу двойным щелчком по значку. В главном окне отображается:

- состояние защиты;
- дата выпуска баз (нормально — не старше 1–3 суток);
- дата последней проверки.

## 3. Что делать при обнаружении угрозы

Программа обрабатывает угрозы автоматически. Уведомление показывается для
сведения, ваше вмешательство обычно не требуется.

| Текст уведомления | Что произошло | Ваши действия |
|---|---|---|
| Объект удалён / вылечен | Угроза устранена | Действий не требуется. Сообщите администратору, откуда получен файл |
| Объект помещён на карантин | Файл изолирован, доступ к нему прекращён | Сообщите администратору. Самостоятельно восстанавливать файл нельзя |
| Обнаружена угроза, требуется перезагрузка | Устранение завершится после перезагрузки | Сохраните работу и перезагрузите компьютер |
| Доступ к файлу заблокирован | Файл запрещён политикой | Обратитесь к администратору, если файл нужен для работы |
| Доступ к устройству заблокирован | Подключение устройства не разрешено | Обратитесь к администратору |

**Немедленно сообщите администратору, если:**

- уведомления об угрозах появляются многократно подряд;
- уведомление появилось после открытия вложения электронной почты или
  файла со съёмного носителя;
- компьютер стал работать заметно медленнее, появились неизвестные окна;
- файлы стали недоступны, изменились их имена или расширения;
- программа защиты неожиданно завершилась.

Признаки в последних двух строках могут указывать на действие программы-
вымогателя. В этом случае: **не выключайте компьютер**, отсоедините сетевой
кабель и немедленно обратитесь к администратору. Выключение может привести
к утрате сведений, необходимых для разбирательства.

## 4. Что запрещено

| Запрещено | Причина |
|---|---|
| Останавливать, удалять, изменять параметры программы защиты | Рабочее место остаётся без защиты, событие фиксируется как нарушение |
| Завершать процессы программы через диспетчер задач | То же |
| Устанавливать другое средство антивирусной защиты | Одновременная работа двух средств приводит к отказу обоих |
| Отключать сетевой кабель для «ускорения работы» | Рабочее место перестаёт получать обновления и настройки |
| Восстанавливать файлы из карантина самостоятельно | Возможно повторное заражение |
| Передавать свои учётные данные другим лицам | Действия будут отнесены на вас |
| Подключать неучтённые съёмные носители | Основной путь проникновения вредоносных программ в изолированную сеть |

Все перечисленные действия регистрируются и передаются на сервер
управления.

---

## 5. Обычные ситуации, не требующие обращения

| Ситуация | Пояснение |
|---|---|
| Кратковременное замедление работы компьютера | Выполняется проверка по расписанию, обычно ночью или при простое |
| Уведомление о необходимости перезагрузки | Применяется обновление; перезагрузите в удобное время в течение рабочего дня |
| Открытие большого файла занимает больше времени | Файл проверяется перед открытием |
| Программа сообщает об устаревших базах после отпуска | Обновление загрузится автоматически в течение часа после включения |

---

## 6. Порядок обращения к администратору

При обращении сообщите:

1. имя компьютера (Пуск → Параметры → Система → О системе, либо на наклейке);
2. точный текст уведомления или его снимок экрана;
3. время возникновения;
4. что вы делали непосредственно перед этим (открывали вложение, подключали
   носитель, устанавливали программу).

Снимок экрана делается клавишей `Print Screen` с последующей вставкой в
документ.

**Контакты:** `<уточняется>`
**Время реагирования при обнаружении угрозы:** незамедлительно
**Время реагирования по прочим вопросам:** в течение рабочего дня

---

## 7. Ответственность

Пользователь несёт ответственность за:

- сохранность своих учётных данных;
- своевременное сообщение о событиях, указанных в разделе 3;
- соблюдение запретов, перечисленных в разделе 4.

Порядок работы с сведениями ограниченного распространения установлен
отдельными документами и настоящим руководством не заменяется.
