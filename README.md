# kscDeployment

Комплект развёртывания и эксплуатации Kaspersky Security Center на
Windows Server 2022 с MariaDB в аттестованном сегменте сети `10.20.30.0/24`.

Репозиторий содержит сценарии установки и настройки по типам узлов,
профили защищённости, эксплуатационную документацию и схемы с таблицами
информационных потоков.

---

## Условия, определившие проектные решения

| Условие | Решение |
|---|---|
| Управление только с АРМ администратора `10.20.30.15` | Порты управления Сервера открыты только для этого адреса и согласованного перечня смежных СЗИ; служебные порты Агентов — для всего сегмента |
| Сегмент `/24`, около 50 узлов, предел адресации 254 | Сервер администрирования и СУБД совмещены на одном узле; размер сети в мастере установки выбран с запасом |
| Хранение сведений — один год | Срок хранения событий, отчётов и журнала действий администраторов — 365 суток; предел числа событий задан заведомо выше годового объёма |
| Средства управления конфигурацией не применяются | Все действия выполняются сценариями по мере необходимости; заготовки ролей Ansible в `ansible/` намеренно нерабочие |
| Статическая адресация | Перечень узлов ведётся вручную; узлы вне домена учитываются в `hosts/standalone/inventory.csv` |
| Изолированный контур | Обращения к внешним сетям отсутствуют, участие в облачной службе репутации отключено |

## Порядок применения

### 1. Заполнить параметры

Перед первым запуском приведите в соответствие фактическим значениям:

- `common/config.ps1` — параметры для сценариев Windows;
- `hosts/linux-debian/common.sh` — те же параметры для сценариев Debian.

Обязательно подлежат замене шаблонные значения:

| Параметр | Шаблонное значение | Чем заменить |
|---|---|---|
| `DomainFqdn` | `domain.local` | Фактическое имя домена |
| `DomainNetBios` | `DOM` | Фактическое краткое имя домена |
| `KscIp` | `10.20.30.20` | Фактический адрес Сервера |
| `SecurityToolsHosts` | пусто | Адреса смежных средств защиты |
| `SiemHost` | пусто | Адрес системы мониторинга событий |

Значения в двух файлах должны совпадать: единого источника нет намеренно,
чтобы сценарии Debian не зависели от наличия PowerShell.

### 2. Развернуть Сервер администрирования

```powershell
cd hosts\ksc-server
.\00_Prepare-Host.ps1
.\01_New-DiskLayout.ps1 -Mode ShrinkC -SystemSizeGB 120 -DbSizeGB 150   # если тома не созданы
.\10_Set-Firewall.ps1
.\20_Install-MariaDB.ps1 -MsiPath <путь к MSI>
.\30_Install-KscServer.ps1 -SetupPath <путь к setup.exe>
.\35_Install-WebConsole.ps1
.\40_Set-PostInstall.ps1
.\50_Backup-KscServer.ps1 -Register -Time 01:30
.\hardening\Invoke-Hardening.ps1
.\60_Test-Deployment.ps1
```

### 3. Подготовить домен и развернуть Агенты

```powershell
cd hosts\dc-gpo
.\00_New-KscAccounts.ps1
.\10_New-AgentGpo.ps1 -VerifyOnly
.\20_Test-AgentDeployment.ps1        # контроль охвата
```

Узлы Debian:

```bash
cd hosts/linux-debian
sudo ./00_prepare-host.sh
sudo ./10_install-netagent.sh /path/klnagent64_<ver>_amd64.deb
sudo ./20_install-kesl.sh /path/kesl_<ver>_amd64.deb
sudo ./30_test-agent.sh
sudo ./hardening/harden.sh --check
```

Узлы вне домена — `hosts/standalone/00_New-StandalonePackage.md`.

Подробный порядок с обоснованием каждого шага — в руководстве
администратора `docs/02_admin_guide`.

## Особенности сценариев

- **Обратимость.** Сценарии, изменяющие состояние узла, поддерживают
  предварительный просмотр (`-WhatIf` в PowerShell, `--check` в Bash) и
  сохраняют данные для отката: изменения реестра — в файл отката, изменяемые
  файлы Linux — с суффиксом `.ksc-bak-<дата>`.
- **Секреты.** Пароли не хранятся в репозитории: сценарии запрашивают их при
  выполнении, передают в дочерние процессы и удаляют временные файлы в блоке
  завершения. Пароли не записываются в журналы.
- **Разрушительные операции.** Разметка диска и сброс правил межсетевого
  экрана требуют явного подтверждения.
- **Проверки перед действием.** Установка не начинается, если не выполнены
  предпосылки: разрешение имени Сервера, доступность порта, наличие Агента
  перед установкой средства защиты.

## Состояние проверки

| Что проверено | Как |
|---|---|
| Синтаксис сценариев Bash | `bash -n` |
| Корректность файлов схем | Разбор XML |
| Отсутствие паролей в файлах | Просмотр вручную |
| Работа сценариев PowerShell | **Не проверялась**: требуется Windows Server 2022 |
| Ключи тихой установки Сервера администрирования | **Не проверялись**: различаются между выпусками, подлежат сверке с документацией применяемого выпуска |
| Совместимость MariaDB 10.11 с выпуском KSC | **Не проверялась**: подлежит сверке по документации применяемого выпуска |
| Совместимость ядра Debian с KESL | **Не проверялась**: перечень поддерживаемых ядер ограничен |

Сценарии PowerShell написаны для Windows PowerShell 5.1 — версии, входящей
в состав Windows Server 2022; конструкции, требующие PowerShell 7,
не применяются.
