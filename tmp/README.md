# tmp

Каталог для образцов документов и рабочих материалов.

Содержимое каталога **не входит в состав системы** и не является
эксплуатационной документацией. Образцы, размещённые здесь, служат основой
для приведения документов каталога `docs/` к принятой в организации форме.

Не размещайте здесь файлы, содержащие пароли, ключи и сертификаты:
каталог отслеживается системой контроля версий.
