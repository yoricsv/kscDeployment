# Роль klnagent

Установка и настройка Агента администрирования KSC на узлах Debian.

Соответствует сценарию `hosts/linux-debian/10_install-netagent.sh`.

Роль не реализована: каталог содержит структуру и перечень задач,
которые должны быть выполнены. Заполняется при переходе к автоматизированному
управлению конфигурацией.

## Планируемые задачи

1. Проверка разрешения имени Сервера и доступности порта 13000/tcp
   (без этого установка бессмысленна — Агент не подключится).
2. Копирование пакета `.deb` с узла управления.
3. Установка пакета.
4. Запуск `postinstall.pl --autoinstall` с файлом ответов, сформированным
   из шаблона; файл ответов удаляется после установки.
5. Включение и запуск службы `klnagent64`.
6. Правило межсетевого экрана: 15000/udp только с адреса Сервера.
7. Проверка связи `klnagchk -sendhb`.

## Переменные

| Переменная | Назначение |
|---|---|
| `ksc_server_fqdn` | Имя Сервера (именно имя: в сертификате указано оно) |
| `ksc_agent_port` | Порт подключения Агента, по умолчанию 13000 |
| `klnagent_deb_src` | Путь к пакету на узле управления |
| `klnagent_uninstall_password` | Пароль защиты от удаления (только для узлов вне домена) |
