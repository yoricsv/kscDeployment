# Роль debian_hardening

Базовый профиль защищённости узла Debian.

Соответствует сценарию `hosts/linux-debian/hardening/harden.sh`.
Роль не реализована — см. пояснение в `ansible/README.md`.

## Планируемые задачи

1. SSH: только ключи, без входа root, ограничение источника подключений
   адресом АРМ администратора.
2. Межсетевой экран: запрет входящих, кроме SSH с АРМ и 15000/udp с Сервера.
3. Параметры ядра (`/etc/sysctl.d/99-ksc-hardening.conf`).
4. Правила аудита (`/etc/audit/rules.d/99-ksc.rules`).
5. Отключение автоматических обновлений и проверка источников APT.
6. Контроль учётных записей с UID 0 и пустыми паролями.

## Особенность

Роль изменяет параметры доступа к узлу. Ошибка в конфигурации SSH способна
привести к потере управления, поэтому реализация обязана проверять
конфигурацию (`sshd -t`) до перезапуска службы и сохранять резервные копии
изменяемых файлов.
