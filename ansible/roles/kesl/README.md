# Роль kesl

Установка Kaspersky Endpoint Security для Linux.

Соответствует сценарию `hosts/linux-debian/20_install-kesl.sh`.
Роль не реализована — см. пояснение в `ansible/README.md`.

## Планируемые задачи

1. Проверка, что Агент администрирования установлен и активен
   (без него узел не получит политику и лицензию).
2. Проверка версии ядра по матрице совместимости.
3. Установка пакета и запуск `kesl-setup.pl --autoinstall`.
4. Параметры: KSN отключён, источник обновлений — хранилище Сервера KSC,
   лицензия не задаётся локально (назначается политикой).
5. Проверка `kesl-control --get-app-info`.

## Переменные

| Переменная | Назначение |
|---|---|
| `kesl_deb_src` | Путь к пакету на узле управления |
| `kesl_use_ksn` | Участие в KSN; в изолированном контуре — `false` |
| `kesl_update_source` | Источник обновлений, `SCServer` — хранилище KSC |
